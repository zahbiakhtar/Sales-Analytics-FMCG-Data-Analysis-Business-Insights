# 🛒 FMCG Sales Performance Analysis & Business Insights

## 📌 Project Overview
This project focuses on analyzing **FMCG (Fast-Moving Consumer Goods) sales data** using **Microsoft Excel** to evaluate revenue performance, identify sales trends, and support **data-driven business decisions**.

The goal is to transform raw sales data into meaningful insights that help stakeholders understand:
- How revenue is performing
- Which products are performing best
- How sales are growing over time

---

## 🛠️ Tools & Technologies
- Microsoft Excel  
- Power Query  
- Pivot Tables  
- DAX (Basic Measures)  

---

## 🎯 Project Objectives
- Analyze **total revenue**
- Measure **sales growth**
- Evaluate **product performance**
- Identify **high and low performing segments**
- Provide **clear and actionable business insights**

---

## 🔄 Data Preparation
The dataset was processed using **Power Query** to ensure accuracy and usability.  
The following steps were applied:

- Data cleaning  
- Removing inconsistencies  
- Transforming raw data into structured tables  
- Preparing the data model for analysis  

This ensured the data was reliable and analysis-ready.

---

## 📊 Data Analysis
Sales data was analyzed using:

- **Pivot Tables** for summarizing large datasets  
- **Sales domain metrics** such as:
  - Total Revenue  
  - Sales Growth  
  - Product-wise Performance  
- **Basic DAX Measures** to calculate key business values  

These techniques helped in understanding sales patterns and performance variations.

---

## 🎨 Reporting & Visualization
To improve readability and stakeholder communication:

- **Conditional formatting** was used to highlight important trends  
- High and low performance areas were visually emphasized  
- **Report beautification techniques** were applied for a clean and professional layout  

---

## 🏆 Final Outcome
The final Excel report provides:

- A clear view of **overall sales performance**
- Insights into **top-performing and low-performing products**
- Visibility into **sales growth trends**
- A **business-friendly dashboard** for stakeholders  

This project demonstrates how Excel can be effectively used for **sales analytics and business intelligence** in the FMCG domain.
